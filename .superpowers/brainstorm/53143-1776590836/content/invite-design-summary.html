Frontend Invite UI — 完整设计总结

3 个部分：Creator 管理、邀请 Modal、Joiner 流程

Part 1: Creator — ConfigPanel 更新

文件: ui/src/components/panels/ConfigPanel.tsx（修改）

现有布局保持不变，新增 2 个区域：

  • LLM Config — 不变
  • Members — 不变，末尾加 + invite member 按钮
  • Active Invites — 新增，列出所有未撤销 token（类型、用量、剩余时间、撤销按钮）
  • Pending Requests — 新增，仅 audit token 有数据时显示。每条：申请人名 + 申请理由 + approve/reject 按钮

Part 2: Creator — Invite Modal

文件: ui/src/components/common/Modal.tsx（新建）、ui/src/components/invite/CreateInviteModal.tsx（新建）

点击 + invite member 打开 modal：

  • 状态 1（表单）：选类型(open/audit) → 选角色(member/admin/readonly) → 填参数(max_uses, max_members, expires) → GENERATE
  • 状态 2（成功）：显示生成的链接 + COPY 按钮 + 摘要信息 → CREATE ANOTHER / DONE

Part 3: Joiner — Join 流程

文件: ui/src/components/setup/SetupWizard.tsx（修改）、ui/src/components/setup/StepJoin.tsx（新建）

两个入口：

  • 入口 A：SetupWizard StepWelcome 加 "Join Existing" 按钮 → 新增 StepJoin（粘贴 invite link → 显示 Ring 信息 → 输入 display_name → join）
  • 入口 B：安装导航页的"继续加入"按钮跳转到 localhost:7420，URL 带 token + creator_ip 参数，前端自动检测并进入 Join 流程

Join 后走 POST /api/join/local（open 类型）或 POST /api/join/apply + 轮询（audit 类型）
