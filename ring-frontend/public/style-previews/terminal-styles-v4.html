层级关系说明

concept.html
Ring Super 全局
  ⚡ AI 助手，随时可呼出，跨所有 Ring 工作

Ring Group 空间
  ◈ 一个群组知识协作空间 = 一个 Git 仓库
  ├── 包含多个 Session
  ├── 包含 Nodes (文档/知识节点)
  └── 有成员权限管理

Ring Session 会话
  › 一个独立对话上下文，属于某个 Ring
  ├── 有自己的聊天历史
  ├── 可以引用/导出 Nodes
  └── 可切换到同 Ring 的其他 Session

📚 三者关系

Ring Super 是全局 AI 入口；Ring Group 是项目/团队空间；Session 是 Ring 内的独立对话线程。

navigation.html
⚡ Super › ◈ project-alpha › › session-42
如何切换：
• ⚡ 点击顶部左侧 → 呼出 Super 面板
• ◈ 点击 Ring 名称 → 展开 Ring 列表切换
• › 左侧栏 Session 列表，或 @ 提及切换

🧭 切换导航

顶部层级栏 + 左侧边栏，构成双维度导航。快捷键 ⌘K 打开 Super，@ 切换 Session。
