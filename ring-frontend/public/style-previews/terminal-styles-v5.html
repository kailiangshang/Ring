概念解释

concepts.html
⚡ Ring Super 全局
全局 AI 助手，跨所有 Ring 工作，随时可呼出
◈ Ring Group 空间
群组知识空间 = 一个 Git 仓库，包含多个 Session
✧ Ring Self 身份
用户在各 Ring 中的身份刻画，未来支持 Self 间对话
› Ring Session 会话
Ring 内的独立对话线程，有自己的上下文

✧ Ring Self

Self 是用户在 Ring 中的身份投影，保留用户在特定 Ring 中的上下文记忆和偏好。

drawer_behavior.html
▸ Graph 面板
点击 "🕸️ Graph" 按钮 → 右侧弹出知识图谱
    可同时查看多个 Ring 的节点关系
▸ Nodes 面板
点击 "📦 Nodes" 按钮 → 右侧弹出节点列表
    点击节点可快速添加到当前 Session 上下文
▸ Settings 面板
点击 "⚙️ Settings" 按钮 → 右侧弹出配置面板
    LLM / GitLab / Export 等配置项
▸ 面板叠加
多个面板可同时打开，左侧面板关闭后右侧自动补位

📋 面板交互

所有面板均从右侧滑出，可叠加、可拖拽、可关闭。
