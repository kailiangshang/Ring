# 使用体验优化点

> 记录时间：2026-04-20

## 1. Chat 气泡左右分布

group chat、super chat、self 的对话框都在同一侧显示，难以区分对话方向。

**现状**：所有消息在同一侧
**期望**：像主流聊天软件一样，AI 消息在左侧，用户消息在右侧

---

## 2. 消息气泡替代横线

当前采用横线分隔消息，与 Markdown 渲染冲突（如 `---` 标题）。

**现状**：横线分隔
**期望**：清晰的对话气泡，区分用户/AI 消息块

---

## 3. AI 回复可折叠

AI 回复内容较长时无法折叠，影响长对话的浏览。

**现状**：完整显示
**期望**：长消息可折叠/展开

---

## 4. 对话 clear / new 功能

日常使用中需要清空当前对话或开启新对话的功能缺失。

**现状**：无
**期望**：`/clear` 或 `/new` 命令快速清空/新建对话

---

## 5. Settings 中缺少个人信息

在 Settings 面板中没有个人信息的设置项，用户无法知道自己是谁。

**现状**：无个人信息入口
**期望**：显示用户名、头像等基本信息

---

## 6. Self Chat 流式输出时阻塞 UI

发送消息后等待完整输出时，点击其他位置会导致界面阻塞。

**现状**：sending 状态阻塞发送，流式输出期间无法交互
**期望**：流式输出期间不应阻塞其他操作

---

## 7. CLI 命令前缀语义冲突 + 缺少权限管理

`@` (addressing) / `#` (reference) / `!` (action) / `%` (meta) 四种前缀存在语义冲突，且不同 Chat 层（Super/Ring/Session）的可用命令没有权限管理。

**现状**：命令前缀含义不清晰，无层级权限区分
**期望**：明确各前缀语义，区分不同 Chat 层的可用命令
