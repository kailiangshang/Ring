# Ring 手动测试指南

> 用于验证开发完成后项目的可用性。按优先级分类，方便分批执行。

---

## 环境准备

```bash
# 终端 1: 启动后端
cd server && cargo run

# 终端 2: 启动前端
cd ui && npm run dev

# 浏览器打开
http://localhost:5173
```

---

## P0 - 必须通过（基本可用门槛）

> 🔴 如果这些失败，项目不可用

### 0.1 Setup 初始化

- [ ] 填写 display_name，点击下一步
- [ ] 选择 LLM provider (openai)
- [ ] 填写 api_key（可以用假的 sk-test）
- [ ] 填写 GitLab URL + token
- [ ] 点击"完成"，跳转 Hub 首页

**成功标志**: 首页出现 "Super Ring" 入口 + Ring 列表

### 0.2 创建第一个 Ring

- [ ] 点击"创建 Ring"按钮
- [ ] 填写名称: `测试组`
- [ ] 填写角色描述: `你是一个助手`
- [ ] 点击"创建"
- [ ] 新 Ring 出现在列表

**成功标志**: 列表显示新 Ring，角色为 "creator"

### 0.3 进入 Ring 空间

- [ ] 点击刚创建的 Ring 卡片
- [ ] 顶部显示 Ring 名称
- [ ] 左侧/右侧有面板切换按钮
- [ ] 底部有输入框

**成功标志**: 能正常进入 Ring 空间，不白屏

### 0.4 Mode 切换

- [ ] 点击 Mode 切换按钮 (Auto)
- [ ] 按钮状态变化
- [ ] **刷新页面**
- [ ] Mode 保持 Auto

**成功标志**: 刷新后 Mode 状态不丢失

### 0.5 成员列表

- [ ] 找到成员列表入口
- [ ] 能看到成员（只有自己）
- [ ] 显示角色正确

**成功标志**: 成员列表正常显示

---

## P1 - 核心功能（主要业务流程）

> 核心功能是否正常工作

### 1.1 Super Ring 对话

- [ ] 点击左侧边栏 "Super Ring" 入口
- [ ] 能看到对话界面
- [ ] 输入 `你好`
- [ ] 点击发送

**成功标志**: 消息发送成功（如果 api_key 有效，应该有流式回复）

### 1.2 Group Ring 对话

- [ ] 在 Ring 空间底部输入框
- [ ] 输入 `你好`
- [ ] 点击发送

**成功标志**: 消息发送成功

### 1.3 Graph 面板

- [ ] 点击 "Graph" 或图谱面板入口
- [ ] 面板打开
- [ ] 能看到图谱区域（可以是空的）

**成功标志**: 面板能打开，不崩溃

### 1.4 Archive 面板

- [ ] 点击 "Archive" 或归档面板入口
- [ ] 面板打开
- [ ] 能看到归档列表区域

**成功标志**: 面板能打开，不崩溃

### 1.5 创建 Session

- [ ] 找到"新建讨论"或 Session 按钮
- [ ] 点击创建 Session
- [ ] 选择 skill: `discussion`
- [ ] 填写标题: `测试讨论`
- [ ] 点击创建

**成功标志**: Session 创建成功，出现在列表

## P2 - 扩展功能（完整功能验证）

> 功能存在但不是必须的

### 2.1 Session 讨论流程

- [ ] 进入刚创建的 Session
- [ ] 能看到 Session 界面
- [ ] 能看到 phase (当前阶段)
- [ ] 能发送消息

**成功标志**: Session 内能正常交互

### 2.2 Self 个人助手

- [ ] 找到 Self/个人助手入口
- [ ] 点击进入 Self 界面
- [ ] 能看到对话输入框
- [ ] 输入消息并发送

**成功标志**: 界面能打开，消息能发送

### 2.3 导出功能

- [ ] 找到导出/Export 按钮
- [ ] 点击导出
- [ ] 选择导出类型

**成功标志**: 导出选项出现，不报错

### 2.4 邀请链接

- [ ] 找到邀请/Invite 按钮
- [ ] 点击生成邀请链接
- [ ] 复制链接

**成功标志**: 链接生成成功，格式正确

### 2.5 成员邀请流程

- [ ] 在成员列表找到邀请按钮
- [ ] 创建邀请链接
- [ ] 链接格式: `http://...:7420/ring/join?token=xxx`

**成功标志**: 链接格式正确

## P3 - 边界情况（锦上添花）

> 体验优化相关

### 3.1 重复 Setup

- [ ] Setup 完成后，再次访问 Setup 页面
- [ ] 跳转到首页（不应允许重复 Setup）

### 3.2 Ring 名称边界

- [ ] 创建 Ring 时输入很长的名称
- [ ] 验证名称显示正常，不截断

### 3.3 Mode 权限

- [ ] 以 member 身份（非 creator）进入 Ring
- [ ] 验证 Mode 切换按钮存在但不可用

### 3.4 错误提示

- [ ] 故意输入错误的 api_key
- [ ] 观察错误提示是否清晰
