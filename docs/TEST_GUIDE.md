# Ring 手动测试指南

## 环境准备

```bash
# 终端 1: 后端
cd server && cargo run        # 监听 :7420

# 终端 2: 前端
cd ui && npm run dev          # 监听 :5173

# 浏览器
open http://localhost:5173
```

---

## P0 — 基本可用

> 以下失败 = 项目不可用

### Setup 初始化

| # | 操作 | 预期 |
|---|---|---|
| 1 | 访问 http://localhost:5173 | 显示 Setup 向导 |
| 2 | 填写 display_name, 选 avatar | 进入 LLM 配置 |
| 3 | 选择 provider, 填 api_key, model | TEST CONNECTION 可点击 |
| 4 | 点击 TEST CONNECTION (可用假 key) | 返回成功或具体错误 |
| 5 | 填 GitLab 或点 Skip | 进入 Done |
| 6 | 点 Done | 显示命令速查表，进入主界面 |
| 7 | 刷新页面 | 自动恢复登录 |

### 创建 Ring

| # | 操作 | 预期 |
|---|---|---|
| 8 | 点击 + 或创建按钮, 填名称描述 | 新 Ring 出现在侧栏 |
| 9 | 点击 Ring 卡片 | 进入 Ring 空间，显示聊天界面 |
| 10 | 点击 Config 面板 | 显示成员/邀请/导出/配置 |

### 基础聊天

| # | 操作 | 预期 |
|---|---|---|
| 11 | Group Ring 输入消息发送 | AI 流式回复, 显示 token 用量 |
| 12 | 点击 Super Ring 入口 | 切换到全局助手 |
| 13 | 输入 `@self 你好` | 打开 Self 浮窗, 消息转发 |

## 严重度定义
