# Ring 手动测试指南

> 前置条件：需要 LLM API Key（OpenAI 或 Ollama）。测试顺序即用户实际使用路径。

## 启动

```bash
cd server && cargo run
# 另一个终端
cd ui && npm run dev
# 打开 http://localhost:5173（Vite dev）或 http://localhost:7420（prod 模式）
```

---

## 1. 首次设置（Setup Wizard）

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1.1 | 打开浏览器，首次访问 | 显示 Setup Wizard 欢迎页 |
| 1.2 | 输入昵称，点下一步 | 进入 LLM 配置页 |
| 1.3 | 选择 provider（openai/ollama），填 model + API key | — |
| 1.4 | 点 TEST | 显示 "LLM config test passed" 或错误信息 |
| 1.5 | 点 NEXT，进入 GitLab 页 | 显示 GitLab 配置 + "Skip GitLab" 按钮 |
| 1.6 | 点 Skip GitLab | 进入 Done 页，显示命令速查表 |
| 1.7 | 点 "Enter Ring" | 进入主界面，左侧显示 Super Ring |

**检查点：**
- [ ] 每步能看到进度吗？目前没有进度指示器，记录感受
- [ ] 点浏览器后退按钮能回到上一步吗？

## 2. Super Ring（全局 AI 助手）

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 2.1 | 在 Super Ring 聊天框输入 "你好" | AI 流式回复，光标闪烁，逐字出现 |

| 2.6 | 修改 Preferences，点 SAVE PREFERENCES | 显示 "Saved!" 反馈 |

| 2.9 | 点 Export 按钮 | 浏览器下载 super-chat.md |
| 2.10 | 输入 `/help` | 显示所有可用命令列表 |
| 2.11 | 连续发 5 条消息 | 聊天区自动滚动到底部 |

**检查点：**
- [ ] SSE 流是否流畅？有无卡顿？
